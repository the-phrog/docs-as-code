# API

API предоставляет доступ к анализатору англоязычных отзывов.

`POST /analysis` проверяет язык поля `text` перед вызовом модели. Если английский язык не подтверждён (включая другой или неопределённый язык), анализ не выполняется, результат не сохраняется и возвращается HTTP `422` с сообщением «Поддерживаются только отзывы на английском языке».

## Основные операции

- `POST /analysis` — определить тональность переданного текста.
- `GET /analysis/{id}` — получить сохранённый результат.
- `GET /models` — получить доступные модели.

## Спецификация

Полное описание запросов, ответов и ошибок: [openapi.yaml](openapi.yaml).
Сервер условный; отправлять реальные запросы не требуется.
