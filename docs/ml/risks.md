# Риски и ограничения

## Потенциальный bias

1. **Риск:** различие языка твитов и отзывов. **Возможное последствие:** снижение качества на специализированной лексике. **Что можно сделать:** проверить macro recall отдельно на отзывах разных тематик. Наличие смещения пока не доказано.
2. **Риск:** недостаточное представительство вариантов английского языка. **Возможное последствие:** неравномерное качество для разных групп пользователей. **Что можно сделать:** оценить ошибки по языковым вариантам на законно собранной выборке. Доступной информации недостаточно для оценки представительности.

## Этические риски

1. **Риск:** отзывы содержат персональные данные. **Последствие:** раскрытие сведений о клиентах. **Снижение риска:** минимизировать хранение, обезличивать данные и ограничивать доступ.
2. **Риск:** оператор чрезмерно доверяет автоматической категории. **Последствие:** ошибочная интерпретация жалобы или несправедливое удаление отзыва. **Снижение риска:** обозначать результат как машинный и проверять существенные решения человеком.
