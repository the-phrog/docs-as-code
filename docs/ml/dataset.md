# Data Sheet

## Общая информация

**Название датасета:** TweetEval, задача sentiment.  
**Источник:** [данные авторов](https://github.com/cardiffnlp/tweeteval/tree/main/datasets/sentiment).  
**Назначение:** обучение и оценка классификации тональности англоязычных твитов.

## Состав данных

**Объём:** 45 615 обучающих примеров, 2 000 валидационных и 12 284 тестовых; значения проверены подсчётом строк файлов авторов.  
**Тип данных:** тексты твитов и категориальные метки.  
**Основные поля / признаки:** текст в файлах `*_text.txt`, метка соответствующей строки в `*_labels.txt`. В `mapping.txt`: 0 — negative, 1 — neutral, 2 — positive.

## Получение данных

TweetEval объединяет существующие задачи в единый формат с фиксированными разбиениями. Источник sentiment — SemEval-2017 Task 4, Sentiment Analysis in Twitter. Подробности первоначального сбора следует смотреть в публикации SemEval.

## Предобработка

Авторы унифицировали формат и разбиения. README сообщает об исправлении небольшого числа обрезанных предложений 17 декабря 2020 года. Полная последовательность очистки в проверенном README не указана. Не следует считать предполагаемые операции очистки установленными фактами.

## Ограничения

Твиты отличаются от развёрнутых отзывов; исторические данные могут не отражать современную лексику. Представительность групп пользователей для нашего сервиса не установлена. Авторы предупреждают, что для отдельных исходных задач и данных Twitter могут действовать дополнительные ограничения использования.

## Использование в проекте

Набор связан с задачей выбранной модели и пригоден как исходный benchmark. Перед использованием в анализаторе отзывов нужна отдельная размеченная выборка англоязычных отзывов; результаты на TweetEval не заменяют эту проверку. Обучение и запуск модели в этой работе не выполняются.
