# Model Card

## Общая информация

**Название модели:** cardiffnlp/twitter-roberta-base-sentiment.  
**Источник:** [Hugging Face](https://huggingface.co/cardiffnlp/twitter-roberta-base-sentiment).  
**Автор / организация:** Cardiff NLP; авторы TweetEval — Francesco Barbieri, Jose Camacho-Collados, Luis Espinosa-Anke, Leonardo Neves.  
**Задача модели:** классификация тональности текста на negative, neutral и positive.  
**Язык:** английский; TweetEval использует англоязычные твиты.  
**Лицензия весов:** не подтверждена по доступному репозиторию авторов; перед использованием нужно проверить карточку модели. Лицензию benchmark нельзя автоматически переносить на веса.

## Использование в проекте

Модель — кандидат для анализа англоязычных отзывов. В сценарии UC-01 система передаёт ей текст из `POST /analysis`, сохраняет тональность и возвращает результат клиенту. Сохранённый результат доступен через `GET /analysis/{id}`, название модели — через `GET /models`. Перед вызовом модели сервис проверяет язык непустого отзыва. Если английский язык не подтверждён, текст модели не передаётся, результат не сохраняется и `POST /analysis` возвращает HTTP 422. Русскоязычный интерфейс документации не означает поддержку русского языка моделью.

## Входные данные

Текст отзыва на английском языке. До внедрения нужно согласовать предобработку с инструкциями модели.

## Выходные данные

Одна из категорий: negative, neutral, positive. API возвращает категорию в поле `sentiment` вместе с идентификатором результата.

## Метрики качества

Репозиторий авторов связывает задачу sentiment с опубликованной моделью. В таблице TweetEval для RoBERTa-Retrained указано 72,8 для sentiment; evaluation_script.py определяет метрику этой задачи как macro recall. Это результат benchmark, а не измеренная точность нашего сервиса и не гарантия качества на отзывах. Собственная оценка не проводилась.

## Ограничения

1. Исходный benchmark основан на Twitter: качество на отзывах отдельно не проверено. Потенциальное ограничение для нашего проекта — перенос между доменами.
2. Потенциальное ограничение для нашего проекта: русскоязычные тексты находятся вне выбранного англоязычного сценария; качество неизвестно.
3. Потенциальное ограничение для нашего проекта: сарказм и смешанная тональность могут приводить к ошибкам; нужны отдельные тестовые примеры.

## Не рекомендуется использовать

Без дополнительной оценки — для русскоязычных отзывов, автоматического удаления отзывов и решений о санкциях в отношении клиентов. Результат должен проверяться оператором при существенных последствиях.
