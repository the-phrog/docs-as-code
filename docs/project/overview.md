# Анализатор отзывов

Сервис определяет тональность текста отзыва: положительную, нейтральную или отрицательную.

Основные пользователи — клиент и оператор. Основные функции: отправка отзыва, определение тональности и просмотр результата.

## Комплект документации

1. Описание проекта — для участников проекта, чтобы понимать назначение сервиса.
2. Требования — для разработчиков и заказчика, чтобы согласовать функции.
3. Архитектура — для разработчиков, чтобы понимать устройство сервиса.
4. API — для интеграторов, чтобы подключать приложения.
5. Документация модели — для специалистов ML, чтобы оценивать применение и ограничения модели.
6. Руководство пользователя — для операторов, чтобы работать с результатами.
